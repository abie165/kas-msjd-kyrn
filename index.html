🔐 Akses Bendahara / Takmir

Jamaah dapat melihat data. Pengelolaan data hanya untuk akun yang telah diberi peran bendahara atau takmir di Firebase.

Memeriksa status aplikasi…

Akun bendahara dibuat melalui Firebase Authentication. Setelah itu, UID akun diberi role di koleksi users melalui Firebase Console.

⚙️ Konfigurasi Aplikasi

Masukkan konfigurasi Firebase di dalam file HTML agar data tersimpan dan tersinkron untuk semua jamaah. Jangan memasukkan kata sandi atau kunci privat Google ke file publik.

Google Drive: gunakan tautan folder bersama untuk bukti transaksi dan bahan ajar. Pengunggahan langsung ke Drive melalui API memerlukan konfigurasi OAuth tersendiri.

Petunjuk singkat

  1. Buat/ pilih proyek di Firebase Console.
  2. Aktifkan Firestore Database dan Authentication (Email/Password).
  3. Salin konfigurasi aplikasi web Firebase ke bagian FIREBASE_CONFIG di bawah.
  4. Pasang Firestore Rules yang aman (disediakan pada catatan pengaturan terpisah).
  5. Unggah file ini sebagai index.html ke repositori GitHub Pages.
